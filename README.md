# HealthLife website (3 pages, Arabic + English)

Files: index.html, transformations.html, payment.html, style.css, site.js, logo.png, images/ (7 photos)

## Upload to GitHub (replace the old files)
1. Open https://github.com/healthlife-coach/healthlife-coach.github.io/upload/main
2. Drag ALL files and the `images` folder in. Same-name files are replaced.
3. Click Commit changes. Wait 1-2 minutes. Open https://healthlife-coach.github.io (Ctrl+F5).

## Edit later
- Text and prices: open site.js, press the pencil icon. Edit inside the `en:` and `ar:` blocks.
- Prices on the page: index.html (search $250) and payment.html; also PLANS in site.js.
- WhatsApp number: site.js, line `var WA = "201050747891"`.
- Bank details: payment.html, search 059102808301.
- Add a photo: upload it into images/ then copy one `<button class="shot"...>` block in transformations.html.
